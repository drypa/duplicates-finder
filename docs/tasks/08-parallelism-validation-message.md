# Валидация `parallelism <= 1` отклоняет значение 1 с вводящим в заблуждение текстом

**Приоритет:** низкий
**Файлы:** `cmd/cmd_find.go`
**Категория:** UX / валидация аргументов

## Проблема

В `run` (`cmd/cmd_find.go:69-71`):

```go
if parallelism <= 1 {
    return errors.New("parallelism must be greater or equal to 1")
}
```

Условие `<= 1` отклоняет значение `1`, при этом текст ошибки утверждает «greater or equal

to 1». То есть минимальное рабочее значение фактически `2`, но сообщение противоречит

логике. Значение `1` (вполне разумный вариант) недоступно.

## Ожидаемое поведение / решение

1. Решить: разрешить `parallelism == 1` (изменить условие на `<= 0`) либо поправить текст

   ошибки, чтобы он отражал требование `>= 2`.
2. Обновить `AGENTS.md` раздел о `--parallelism` в соответствии с принятым решением.

## Acceptance criteria

- Поведение при `parallelism == 1` соответствует задокументированному.
- Текст ошибки не противоречит фактической проверке.
