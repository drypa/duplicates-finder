# Повторное удаление одного файла и вводящий в заблуждение лог при ошибке

**Приоритет:** высокий
**Файлы:** `cmd/cmd_find.go`
**Категория:** корректность удаления / логирование

## Проблема

1. **Повторное занесение одного файла в список удаления.** Если у одного source-файла

   несколько target-дубликатов (одинаковые имена в разных подпапках target), то для

   `DeleteSource` `sourceFile.FullPath` добавляется в `filesToDelete` несколько раз

   (`cmd/cmd_find.go:102`). Повторный `os.Remove` неизбежно вернёт ошибку.

2. **Вводящий в заблуждение лог.** `deleteFile` (`cmd/cmd_find.go:130-136`) игнорирует

   ошибку `os.Remove`: при сбое всё равно печатает `%s deleted`, что неверно сообщает

   пользователю об успешном удалении.

## Ожидаемое поведение / решение

1. Дедуплицировать `filesToDelete` перед подтверждением/удалением (или вести `map` для

   уже запланированных к удалению путей).
2. В `deleteFile` при ошибке печатать сообщение об ошибке и **не** выводить «deleted».

## Acceptance criteria

- Один путь не удаляется дважды.
- При сбое `os.Remove` выводится сообщение об ошибке, а не «deleted».
