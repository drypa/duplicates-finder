# Ошибки молча игнорируются при сравнении файлов

**Приоритет:** низкий
**Файлы:** `cmd/cmd_find.go`
**Категория:** диагностика / обнаруживаемость

## Проблема

При итерации target (`cmd/cmd_find.go:92-93`):

```go
targetFile, err := files.NewFile(target)
if err == nil {
    ...
}
```

При **любой** ошибке создания файла (нет доступа к чтению, файл удалён между обходами,

каталог недоступен и т.п.) файл молча пропускается. Пользователь не видит, что часть

файлов не была проанализирована.

Проблема не ведёт напрямую к удалению без дубликата, но скрывает сбои и может создать

ложное впечатление полноты анализа.

## Ожидаемое поведение / решение

1. Выводить диагностику об ошибке (например, в формате, аналогичном обработке ошибок

   source в `fillSourceFiles`), а не только молча пропускать файл.
2. Не прекращать обход, но информировать о пропущенных файлах.

## Acceptance criteria

- При недоступности файла/каталога в target пользователь видит предупреждение.
- Обход продолжается при одиночных ошибках.
